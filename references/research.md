# Research Reference

## Source Priority

1. Official documentation
2. Official repositories and specifications
3. Standards bodies and primary technical sources
4. Established technical references
5. Community discussions for practical edge cases

## Research Discipline

- Verify current versions for version-sensitive APIs.
- Distinguish facts from recommendations.
- Do not treat search snippets as authoritative evidence.
- Do not invent citations.
- Stop researching when more information no longer changes the implementation decision.

## Research Output

Capture decision-relevant findings: what was verified, why it matters, compatibility constraints, chosen approach and rejected alternatives when useful.

## 🧠 What is IQ∞?

IQ∞ is a public, reusable **master AI engineering skill** designed to make capable AI agents work like disciplined engineering teams instead of one-shot code generators.

## ✨ Capability Matrix

| Layer | What IQ∞ does |
|---|---|
| 🧭 Intent | Requirements, constraints, acceptance criteria |
| 🔎 Research | Primary-source and version-aware research |
| 🏗️ Architecture | Modules, interfaces, data flow, failure paths |
| 💻 Coding | Complete production-oriented implementation |
| 🐛 Debugging | Reproduce → root cause → fix → regression |
| 🧪 Testing | Unit, integration, build, E2E and runtime validation |
| 🔐 Security | Secrets, injection, permissions, dependencies |
| ⚡ Performance | CPU, RAM, network, rendering and mobile constraints |
| 🎨 UI/UX | Responsive, accessible, polished interfaces |
| 📱 Mobile | Small-screen and resource-aware engineering |
| 📚 Memory | Decisions, setup, pitfalls and test commands |
| 🤖 Orchestration | Specialized stages and verification loops |

## 🧬 Why a Master Skill?

A pile of disconnected skills can create conflicting instructions and duplicated behavior. IQ∞ uses **one execution contract** with specialized modes inside it.

> One brain. Multiple engineering disciplines. One verification loop.

## 🚀 Install

Copy `SKILL.md` into the skill directory supported by your AI coding environment, or use this repository as the source for your own agent-skill loader.

The core skill is intentionally platform-neutral and can be adapted to Markdown-based skill systems, repository instruction systems, and agent frameworks.

## 🛡️ Quality Rules

IQ∞ rejects fake test results, fake tool calls, fabricated sources, silent destructive operations, hard-coded secrets, unnecessary rewrites, unfinished placeholders and version guessing.

## 🔬 The Signature Loop


## 🌐 Inspiration

IQ∞ is an original synthesis of recurring patterns across public AI-agent skill ecosystems: skill creation and validation, research workflows, code review, browser/E2E testing, repository automation, frontend design, debugging loops and agent orchestration. It intentionally avoids copying proprietary prompts or large third-party skill files.
